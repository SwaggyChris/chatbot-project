VOICE/TTS REMOVED FROM SWAGGBOT

Removed from this source package:
- Kokoro speech proxy endpoint: app/api/genesis/speech/route.ts
- Kokoro voice server launcher: start-kokoro-voice.bat
- TTS generation/playback queue and voice output controls in GenesisWorkspace.tsx

Run npm install and npm run dev after replacing your local project folder.
